Host一键把这台机器接入云主机

    

      不需要先在网页里找节点：下载脚本 → 拷到要出租的电脑上运行（Windows 双击 .cmd，
      Linux/macOS 在终端执行 sh 脚本名）→ 脚本会检查/引导安装 QEMU，
      再启动 Agent 并自动绑定到你的账户。启动后回到本页刷新，就能发布配置。
    

    

      

      

      

    

    

      

      

      

    

    

      

      

    

    
routed 需要 Linux 网桥和 root/CAP_NET_ADMIN；不填网桥就是最省事的 slirp 模式。
      云主机需要放行 IPv6 入站 TCP 5900-5999（控制台）、20000-29999（SSH/自动端口）
      以及你在配置里显式填写的其它端口；
      Windows 另需启用「Windows Hypervisor Platform」，Linux 需当前用户可读写 /dev/kvm。

    
    

    

    
首次运行会下载约 10MB Agent；没装 QEMU 时脚本会给出安装命令并询问是否代装。
      脚本是一次性的，30 分钟内有效；启动后保持窗口，关掉即停止提供算力。

  


  

    
Sell发布我的虚拟机配置

    

    

    

      Agent 需要以 --vm 启动，并装好 qemu-system-x86_64 与 qemu-img；
      可以直接用上面的「一键接入」脚本，它会处理这些检查和启动。
      发布时使用节点当前上报的 IPv6；slirp 模式跨平台可用，routed 模式需要 Linux 网桥（--vm-bridge）。
